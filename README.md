# FF14 Fan Fest 2026 – 会場ガイド v6

2ページ：ステージ時間表／4つの公式会場マップ。

マップ下のContentsは番号付き。タップでチェックして色を切り替え、選択はブラウザに記憶されます（v5のチェック内容も引き継ぎます）。旧版の「予定時間メモ」は削除し、各コンテンツの開催時間を表示しました。

## 営業時間について
基本の目安：10/31 09:00–21:00、11/01 09:00–20:30。多くのコンテンツは30分前最終受付ですが、個別に異なる場合があります。注記のない標準枠は **開催時間の目安** で、各ブースの確約時間ではありません。

- #17 クイックフォトセッション: 事前予約当選者限定。出演者・時間帯を記載。
- #22 NPC名鑑: 10:00開始。
- #23 FFトレーディングカード: 11:00–20:15。
- 展示・宅配など個別時間未確認の場所は確認が必要と明記。
